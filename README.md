# Mâtcha Studio

Sanity Studio for [matchadesigns.com](https://matchadesigns.com), hosted at https://studio.matchadesigns.com.

```sh
pnpm install
pnpm dev             # http://localhost:3333
pnpm typecheck && pnpm lint && pnpm test
pnpm deploy-graphql  # after schema changes: the Gatsby site reads the GraphQL API
```
